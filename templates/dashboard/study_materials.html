Pattern Questions & Matrix Logic
1. Star Pyramid / Diamond Pattern

For row i (1 to N): Print N - i spaces, then 2*i - 1 stars.

2. Spiral Matrix Traversal

Maintain 4 boundary variables: top, bottom, left, right. Traverse Right → Down → Left → Up, then shrink boundaries inward.

3. Pascal Triangle Matrix

Matrix cell val[i][j] = val[i-1][j-1] + val[i-1][j]. Boundaries j=0 & j=i are always 1.

4. Dynamic Programming 0/1 Knapsack

State dp[i][w] = max profit using items 1..i and weight limit w. dp[i][w] = max(include, exclude).

String Palindrome Verification
def is_palindrome(s):
    # Normalize string
    cleaned = "".join(c.lower() for c in s if c.isalnum())
    
    # Check using pointers
    left, right = 0, len(cleaned) - 1
    while left < right:
        if cleaned[left] != cleaned[right]:
            return False
        left += 1
        right -= 1
        
    return True

Training a Simple Model (Scikit-Learn)
import numpy as np
from sklearn.linear_model import LinearRegression

# Sample mock dataset (Hours Studied vs score)
X = np.array([[2], [4], [6], [8], [10]])
y = np.array([25, 45, 60, 80, 95])

# Fit Linear regression
model = LinearRegression()
model.fit(X, y)

# Predict score for 7 study hours
hours = np.array([[7]])
predicted_score = model.predict(hours)
print(f"Predicted Score: {predicted_score[0]:.2f}")
